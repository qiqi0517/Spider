# Python 程序设计实验大作业计划

## Day 1

* 看完作业要求，确定大概要做什么
* 复习 requests
* 复习 BeautifulSoup
* 学习 CSS Selector
* 学习 JSON / CSV 的基本读写
* 看一下目标网站的 HTML 结构
* 建好项目文件夹

目标：能够自己用 requests + BeautifulSoup 抓到一些数据并保存下来。

## Day 2

* 开始写正式的爬虫
* 分析网页结构
* 写数据解析
* 把需要的数据提取出来
* 处理一些简单的空值和格式问题
* 保存爬取的数据

目标：爬虫基本跑通，能够得到一批比较完整的数据。

## Day 3

* 继续处理爬虫得到的数据
* 学习 SQLite 基础
* 设计数据库中的表
* 把数据存入数据库
* 学习基本的 SELECT 查询

目标：数据能够正常存到数据库里。

## Day 4

* 学习 Django 基本结构
* 创建 Django 项目和 app
* 了解 urls、views、templates
* 学习 Django 如何读取数据库
* 做一个最简单的网页

目标：Django 项目能够正常运行。

## Day 5

* 完成网站主要页面
* 显示数据列表
* 完成数据详情页面
* 调整一下页面样式
* 检查数据库和网页之间的数据是否正常

目标：网站基本可以使用。

## Day 6

* 完成搜索功能
* 可以按照歌曲、歌手等信息进行搜索
* 处理搜索不到数据的情况
* 如果还有时间，可以加排序或筛选

目标：网站可以进行基本的信息检索。

## Day 7

* 学习 pandas 基础
* 用 pandas 读取和处理数据
* 对数据做一些简单统计
* 学习 Matplotlib
* 画几个有意义的图
* 思考从数据中可以得到什么结论

目标：完成基本的数据分析和可视化。

## Day 8

* 把爬虫、数据库、Django、搜索、数据分析全部连起来
* 检查各部分是否能够正常运行
* 修改比较明显的问题
* 暂时停止增加大型新功能

目标：整个项目基本完成，能够从头到尾运行。

## Day 9

* 测试整个项目
* 修复 Bug
* 检查数据是否有重复、缺失、乱码等问题
* 检查网页各个功能
* 整理代码和文件
* 完善 README

目标：得到一个比较稳定的版本。

## Day 10

* 写实验报告
* 整理项目截图
* 检查代码
* 检查 requirements.txt
* 从头运行一次项目
* 最后修改和提交

目标：完成最终版本并提交。

# 时间安排

前 7 天主要完成学习和开发。

第 8 天完成整个项目。

第 9 天留给测试和修改。

第 10 天留给报告和提交。

如果前面进度比较慢，优先保证爬虫、数据库、网站和搜索这些基本功能。
